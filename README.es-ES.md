

# CoD FoV Changers

### [DESCARGAR AQUÍ](https://github.com/AgentRev/CoD-FoV-Changers/releases)

Este repositorio contiene el código fuente y los ejecutables de los cambiadores de FoV que hice para Call of Duty MW2, MW3 y Ghosts. Ya no los estoy desarrollando, sin embargo, si dejan de funcionar debido a una actualización del juego, abre un nuevo issue y veré qué puedo hacer.

Escribí la mayor parte del código; el resto son fragmentos copiados de MPGH.net y Stack Overflow.

No existe una versión para MW2 SP, puedes encontrar una aquí: https://github.com/marvinlehmann/CoD-SCZ-FoV-Changer/releases

### Preguntas frecuentes (FAQ)

- Si tienes problemas para que el cambiador de FoV funcione, intenta esperar a que el mapa cargue antes de iniciar el cambiador.

- Si obtienes el error `System.NullReferenceException IsGameInstalled`, simplemente instala Steam, sucio campesino.

- Si el cambiador de FoV ha dejado de funcionar con [Problem Event Name CLR20r3](https://i.imgur.com/7heWwTW.png), debes [instalar .NET Framework 3.5](https://www.techhit.com/how-to/install-.net-3.5.1/windows7/)

- Si obtienes el error `System.ArgumentException Font`, descarga [MissingFonts.zip](https://github.com/AgentRev/CoD-FoV-Changers/raw/master/MissingFonts.zip) y extrae los archivos en `C:\Windows\Fonts` (si se te pide reemplazar los archivos actuales, elige sí)

- No, no tengo cambiadores de FoV para Mac. Ni siquiera tengo una Mac.
